**1. Operator Aritmatika**
Fungsi operator ini digunakan untuk melakukan operasi pada tipe numerik. 

| Operator | Fungsi      | Contoh |
| -------- | ----------- | ------ |
| +        | Menambahkan | 2 + 2  |
| -        | Mengurangi  | 2 - 2  |
| *        | Mengalikan  | 2 * 2  |
| /        | Membagi     | 2 / 2  |

**2. Operator Perbandingan**
Digunakan untuk membandingkan nilai.

| Operator | Fungsi                           | Contoh |
| -------- | -------------------------------- | ------ |
| =        | TRUE jika kedua nilai sama       | 2 = 2  |
| !=       | TRUE jika kedua nilai tidak sama | 2 != 2 |
| >        | TRUE jika nilai lebih dari       | 2 > 1  |
| <        | TRUE jika nilai kurang dari      | 1 < 2  |

**3. Operator Logika**
Digunakan untuk menggabungkan beberapa kondisi.

| Operator | Fungsi                           |
| -------- | -------------------------------- |
| AND      | TRUE, jika dua nilai TRUE        |
| OR       | TRUE, jika salah satu nilai TRUE |
| NOT      | TRUE jika FALSE                  |
