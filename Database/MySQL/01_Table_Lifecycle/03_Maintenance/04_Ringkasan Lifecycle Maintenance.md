|**Perintah**|**Fungsi Utama**|**Contoh Penggunaan Sintaks**|
|---|---|---|
|**`ADD`**|Menambah kolom baru|`ALTER TABLE t ADD kolom tipe;`|
|**`DROP COLUMN`**|Menghapus kolom|`ALTER TABLE t DROP COLUMN kolom;`|
|**`MODIFY COLUMN`**|Mengubah tipe data/aturan kolom|`ALTER TABLE t MODIFY COLUMN kolom tipe_baru;`|
|**`CHANGE COLUMN`**|Mengubah nama kolom|`ALTER TABLE t CHANGE COLUMN lama baru tipe;`|
|**`RENAME TO`**|Mengubah nama tabel|`ALTER TABLE t RENAME TO nama_baru;`|
