|**Operasi**|**Sintaks Dasar**|**Penggunaan WHERE**|
|---|---|---|
|**Create**|`INSERT INTO tabel (kolom) VALUES (nilai);`|Tidak digunakan|
|**Read**|`SELECT kolom FROM tabel WHERE kondisi;`|Opsional (untuk memfilter data)|
|**Update**|`UPDATE tabel SET kolom = nilai WHERE kondisi;`|**Wajib** (mencegah salah ubah semua data)|
|**Delete**|`DELETE FROM tabel WHERE kondisi;`|**Wajib** (mencegah salah hapus semua data)|
